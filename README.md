**Lung_stack** is a customized adaptation of the Stack single-cell foundation model for fine-tuning on paired lung cancer single-cell RNA-seq data. It extends the original Stack fine-tuning pipeline to support patient-matched pre-treatment and post-treatment samples, with patient-level leave-one-patient-out cross-validation, paired pre/post cell-type-aware sampling, and safeguards for small-sample settings. The current implementation is designed for NSCLC neoadjuvant therapy data, using treatment-naive pre-biopsy cells and post-surgery cells to study therapy-associated cellular state transitions while preserving Stack’s in-context learning framework.
